학교 웹사이트 자동 로그인 확장 프로그램
이 확장 프로그램은 인덕대학교 LMS 및 포털 사이트의 로그인 과정을 자동화하여 편의를 제공하기 위해 만들어진 비공식(Unofficial) 툴입니다.

### ✨ 주요 기능
* 인덕대학교 LMS (lms.induk.ac.kr)
* 인덕대학교 통합로그인 (sso.induk.ac.kr)
사이트 자동 로그인

### 🔧 사용 및 설치 방법

1. 확장 프로그램 설치하기

이 프로젝트 폴더를 컴퓨터의 안전한 위치에 다운로드하거나 저장합니다. (폴더를 삭제하면 프로그램이 동작하지 않습니다.)
<img width="452" height="393" alt="image" src="https://github.com/user-attachments/assets/f4d31d46-7a71-494d-9814-4f1c072b9af8" />

깃허브 Code 버튼 => zip파일로 다운로드 후 압축 해제

크롬 브라우저를 열고 주소창에 `chrome://extensions` 를 입력하여 확장 프로그램 관리 페이지로 이동합니다.

페이지 오른쪽 상단에 있는 '개발자 모드(Developer mode)' 스위치를 켭니다.

왼쪽 상단에 나타난 '압축해제된 확장 프로그램을 로드합니다(Load unpacked)' 버튼을 클릭합니다.
<img width="834" height="479" alt="image" src="https://github.com/user-attachments/assets/ee48623d-8471-4ebf-8438-41cc83733e8b" />
파일 탐색기가 열리면, 다운로드한 프로젝트 폴더 자체를 선택하고 '폴더 선택' 버튼을 누릅니다.

설치가 완료되면 확장 프로그램 목록에 '학교 자동 로그인'이 추가된 것을 확인할 수 있습니다.


2. 로그인 정보 저장하기
   브라우저 오른쪽 상단의 퍼즐 모양(🧩) 아이콘을 클릭하여 확장 프로그램 목록을 엽니다.
<img width="508" height="445" alt="image" src="https://github.com/user-attachments/assets/bfd27062-d09f-45b2-866d-8de572224a64" />


'학교 자동 로그인' 항목을 찾아 마우스 오른쪽 버튼을 클릭한 후, '옵션(Options)' 메뉴를 선택합니다.

열리는 설정 페이지에서 학교에서 사용하는 아이디(학번)와 비밀번호를 입력하고 '저장' 버튼을 누릅니다.
<img width="525" height="449" alt="image" src="https://github.com/user-attachments/assets/1d95fcc0-e999-47c7-8580-934d87e9eb52" />


3. 자동 로그인 실행하기
   학교 로그인 페이지(LMS 또는 포털)에 접속합니다.

페이지가 로드되면 "로그인 하시겠습니까?" 라는 확인 창이 나타납니다.

'확인' 버튼을 누르면 저장된 정보로 로그인이 자동으로 진행됩니다.
<img width="1213" height="216" alt="image" src="https://github.com/user-attachments/assets/f807ede8-9713-4c3f-91ac-ded1cb1679b5" />


⚠️ 주의사항 및 면책 조항
이 확장 프로그램은 학생의 편의를 위해 제작된 비공식 프로그램이며, 인덕대학교에서 제작하거나 보증하지 않습니다.

아이디와 비밀번호는 사용자의 PC 내 크롬 브라우저 저장소에만 저장될 뿐, 개발자를 포함한 그 누구에게도 전송되지 않습니다.

이 프로그램을 사용함으로써 발생하는 모든 잠재적인 문제(계정 잠금, 정보 유출 등)에 대한 책임은 전적으로 사용자 본인에게 있습니다.

학교 웹사이트의 구조가 변경될 경우, 이 프로그램은 예고 없이 작동을 멈출 수 있습니다.
